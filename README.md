# Anceva Bot

Бот для детского коррекционного центра Марии Анцевой (Караганда).
Telegram-бот принимает родителей, отвечает на вопросы, записывает на диагностику.
Веб-админка даёт одно окно для Марии и администратора — смотреть чаты, расписание, оплаты.

**Опубликованные материалы по проекту:**
- 🌿 [Анализ чатов и план работы бота](https://romanzhan.github.io/anceva-analysis/) — для Марии
- 🔧 [Технический проект](https://romanzhan.github.io/anceva-analysis/tech.html) — архитектура, экраны, логика

Исходный код — в этом же репозитории, папка `app/` и остальные технические файлы.

## Как запустить у себя

Подробная пошаговая инструкция — в [`DEPLOY.md`](./DEPLOY.md). Там же — как задеплоить бесплатно на первый месяц.

Коротко:

```bash
git clone https://github.com/romanzhan/anceva-analysis.git anceva-bot
cd anceva-bot
python -m venv .venv
.venv\Scripts\activate            # Windows
pip install -e ".[dev]"
copy .env.example .env             # и заполни токены
alembic upgrade head
python -m scripts.seed_owner
just run                           # все 4 процесса разом
```

## Структура проекта

```
app/
├── bot/           # клиентский бот в Telegram (родители)
├── admin_bot/     # бот-пульт для Марии и Агнии
├── web/           # веб-админка (FastAPI + htmx + Tailwind)
├── miniapp/       # Telegram Mini App: согласие ПД + анкета
├── common/        # конфиг, логи, ошибки
├── domain/        # бизнес-правила (возраст, прайс, эскалация)
├── db/            # база данных (SQLAlchemy, миграции)
├── llm/           # клиент Gemini + мастер-промт
├── dialog/        # логика диалога (FSM, эскалация)
├── scheduler/     # фоновые задачи (напоминания, follow-up)
└── integrations/  # Kaspi и другие внешние сервисы

index.html         # публичный отчёт для Маши → GitHub Pages /
tech.html          # технический документ → GitHub Pages /tech.html
```
