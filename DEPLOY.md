# Запуск бота — пошаговая инструкция

Простыми словами. Если ты ни разу не деплоил ботов — ничего, пройдёшь по шагам и всё заработает.

Есть две цели:
1. **Запустить локально у себя** — проверить, что всё живое, потыкать кнопки, попереписываться с ботом.
2. **Задеплоить в интернет** — чтобы бот работал 24/7, без твоего ноутбука.

Мы сделаем обе, но начнём с ключей.

---

## Часть 1. Что у нас спросит бот (и где это взять)

Нам нужны **5 вещей**. Примерно 15–20 минут на всё.

### 1. Токен клиентского бота

Это сам бот, с которым будут общаться родители.

1. Открой в Telegram **@BotFather** — официальный бот от Телеграма для создания ботов.
2. Напиши ему `/newbot`.
3. Придумай **имя** — то, что будет наверху чата. Например: `Центр Коррекции Речи Анцевой`. Можно по-русски.
4. Придумай **username** — заканчивается на `bot`. Например: `anceva_center_bot`. Если занят — поменяй немного.
5. BotFather пришлёт тебе **токен** вида `8142:AAH...zwq`. Это длинная строка с двоеточием.
6. **Скопируй её и пришли мне** — подпишу «клиентский».

Пока бот создан — настрой ему красивое:
- `/setdescription` → короткое описание: «Виртуальный помощник центра. Поможем записать ребёнка на диагностику.»
- `/setabouttext` → текст в профиле: «Центр Коррекции Речи Марии Анцевой, Караганда. 🌿»
- `/setuserpic` → аватар (любая картинка центра)

### 2. Токен админского бота

Это второй бот — твой пульт для управления, куда тебе будут приходить уведомления.

Повтори те же шаги:
1. `/newbot` в @BotFather
2. Имя: `Anceva Admin` или как нравится
3. Username: `anceva_admin_bot` (или другое свободное)
4. Скопируй токен и пришли мне с подписью «админский».

### 3. Твой Telegram user_id

Нужен, чтобы бот знал, кого пускать в админку (первого админа — тебя).

1. Открой в Telegram **@userinfobot**.
2. Нажми `/start`.
3. Он напишет цифру вида `123456789`. Это твой ID.
4. **Пришли мне эту цифру.**

Позже, когда Мария заведёт себе Telegram и нужен будет её доступ — повторим это же. Админов добавлять можно сколько угодно.

### 4. API-ключ Gemini

Это «мозги» бота — без него он ничего не говорит. Мы берём бесплатный уровень Google AI.

1. Открой https://aistudio.google.com/app/apikey
2. Войди через свой Google-аккаунт (у тебя уже настроен биллинг — Google помнит).
3. Нажми **Create API key**.
4. Выбери проект (или создай новый, как удобно).
5. Скопируй ключ вида `AIza...` (длинная строка).
6. **Пришли мне ключ** с подписью «Gemini».

Лимиты бесплатного:
- 15 запросов в минуту
- 1 500 запросов в сутки

Для старта — за глаза. Если перерастём, включим платный — деньги со счёта Google.

### 5. Kaspi-ссылка для оплаты

Та самая, на которую родители будут оплачивать брони диагностик.

1. Открой приложение **Kaspi** на телефоне.
2. Внизу → **«Мой Kaspi»** → **«Переводы»** → **«QR на оплату»** (или «Принимать платежи»).
3. Там будет ссылка вида `https://pay.kaspi.kz/pay/XXXXXX`.
4. **Пришли мне эту ссылку.**

Если у Марии Сергеевны уже есть оформленный магазин в Kaspi — лучше использовать его, там удобнее принимать деньги и видеть отчёты.

## Часть 3. Локальный запуск

На этом этапе ты ещё ничего не деплоишь, просто проверяешь что работает на твоём ноутбуке.

### Установка (один раз)

1. Если ещё нет Python 3.12 — поставь с https://www.python.org/downloads/ (галочку «Add Python to PATH» при установке).
2. Проверь: в PowerShell `python --version` должен показать 3.12 или выше.
3. Клонируй репо (если ещё не клонировал):
   ```
   git clone https://github.com/romanzhan/anceva-analysis.git anceva-bot
   cd anceva-bot
   ```
   У тебя он и так уже есть, просто нужно в папку зайти.
4. Установка зависимостей (это скачает все нужные библиотеки):
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -e ".[dev]"
   ```

### Первый запуск

1. Скопируй `.env.example` → `.env` и заполни ключи (я тебе дам готовую версию).
2. Создай базу данных (одна команда):
   ```
   alembic upgrade head
   ```
3. Добавь себя как владельца админки:
   ```
   python -m scripts.seed_owner
   ```
4. Запусти всё сразу:
   ```
   honcho start -f Procfile.dev
   ```

Что произойдёт:
- Клиентский бот станет слушать сообщения в Telegram
- Админский бот тоже слушает (отдельно)
- Веб-админка поднимется на `http://localhost:8000`
- Планировщик фоновых задач включится

### Что тестировать

1. Найди своего клиентского бота в Telegram по `@anceva_center_bot` (или как ты его назвал).
2. Напиши ему `/start` — должен поздороваться.
3. Напиши что-то вроде «Здравствуйте, сыну 3 года, не говорит» — бот должен пойти по сценарию.
4. Зайди на `http://localhost:8000` в браузере — редиректнёт в окно входа через Telegram.
5. Войди через Telegram — увидишь админку.

Если что-то не работает — скинешь мне логи (они будут в том же окне PowerShell), я починю.

## Часть 4. Бесплатный деплой на первый месяц

Локально крутить бота неудобно — нужно, чтобы твой комп был всегда включён.
Решение — **хостинг**, который держит бота 24/7 сам.

### Варианты

| Сервис | Бесплатно? | Нужна ли карта? | Сложность |
|---|---|---|---|
| **Fly.io** | Да, впритык, но точно хватит на тестовый месяц | Нужна, но не спишет | Средняя |
| **Railway** | Нет, от $5/мес сразу | Да, спишет $5 | Самая простая |
| **Render** | Да, но засыпает через 15 мин — не подходит для бота | Нет | — |
| **Koyeb** | Да, 1 сервис навсегда бесплатно | Да | Средняя |

**Моя рекомендация — Fly.io.** Бесплатный уровень $5 кредитов в месяц — хватит с запасом для теста. После месяца, если всё понравится, переходим на Railway или остаёмся на Fly (там ~$2/мес без кредита).

### Как задеплоить на Fly.io

1. **Регистрация.**
   - Зарегься на https://fly.io/app/sign-up
   - Привяжи карту (нужно для защиты от ботов, списаний не будет, пока сам не включишь платный уровень).

2. **Установи Fly CLI.**
   В PowerShell:
   ```
   powershell -Command "iwr https://fly.io/install.ps1 -useb | iex"
   ```
   Потом перезапусти PowerShell.

3. **Авторизуйся.**
   ```
   fly auth login
   ```

4. **Запусти приложение.**
   ```
   cd anceva-bot
   fly launch
   ```
   Fly спросит:
   - Имя приложения — например, `anceva-bot` (должно быть уникальным, если занято — добавь цифру)
   - Регион — выбери ближайший (`Frankfurt fra` или `Warsaw waw` — быстро до Казахстана)
   - Базу данных — **не** создавай (у нас SQLite в volume)
   - Развернуть сейчас — **нет**, сначала настроим секреты

5. **Создай persistent volume для базы.**
   ```
   fly volumes create anceva_data --size 1 --region fra
   ```
   (вместо `fra` поставь свой регион)

6. **Залей секреты** (это переменные окружения на сервере — в открытом виде нигде не видны):
   ```
   fly secrets set BOT_TOKEN_CLIENT="8142:..."
   fly secrets set BOT_TOKEN_ADMIN="8143:..."
   fly secrets set GEMINI_API_KEY="AIza..."
   fly secrets set OWNER_TG_USER_ID="123456789"
   fly secrets set KASPI_PAY_LINK="https://pay.kaspi.kz/pay/..."
   fly secrets set WEB_SESSION_SECRET="случайная_длинная_строка"
   fly secrets set DATABASE_URL="sqlite+aiosqlite:////data/anceva.sqlite"
   ```

7. **Деплой.**
   ```
   fly deploy
   ```

8. **Проверка.**
   ```
   fly status            # видно, запущен ли
   fly logs              # видны ошибки в реальном времени
   ```

9. **Найди бота в Telegram и напиши `/start`** — он должен ответить уже с серверной стороны.

### Когда переходить на платный

Когда:
- Появится реальный поток клиентов (больше 50 диалогов в день)
- Понадобится домен (Mini App требует HTTPS со своего домена, а не `.fly.dev`)
- Захочется Postgres вместо SQLite

Тогда Railway за $5/мес или платный Fly с ~$5–10/мес.

## Часть 5. Что дальше

После того как всё задеплоено и бот живёт в интернете — следующие шаги:

1. **Поиграть 2–3 дня в shadow mode** — в `.env` стоит `FEATURE_SHADOW_MODE=true`. В этом режиме бот отвечает, но его ответы параллельно летят тебе в логи — чтобы ты видела, что он пишет. Если что-то не то — правим промт.
2. **Дать Маше ссылку на бота** — пусть она сама пообщается с ним как клиент, найдёт косяки.
3. **Купить домен** (когда ты будешь готов) — тогда можно будет подключить Mini App (анкета), красивый URL, профессиональный вид.
4. **Наполнить админку живыми данными** — сейчас там все экраны-заглушки. После первых реальных клиентов делаем Inbox, карточки, оплаты.

## Если что-то не работает

- **Бот не отвечает:** проверь `fly logs` — скорее всего токен неправильный или Gemini вернул ошибку.
- **Не могу войти в админку:** проверь, что `OWNER_TG_USER_ID` — именно твой id (через @userinfobot).
- **Бот отвечает странное:** скорее всего, промт поймал какой-то edge case. Пришли мне пример — подправлю.
- **Вообще всё упало:** `fly deploy` ещё раз или пиши мне.

Не стесняйся — каждый ступор на десять минут в твоей голове решается за минуту с моей стороны.
